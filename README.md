# Salt SMB

使用 Rust、Slint 和纯 Rust SMB2/3 客户端构建的桌面文件客户端。

## 运行

安装 Rust 工具链和系统图形环境，在项目目录运行：

```sh
cargo run --release
```

首次构建需要访问 crates.io 下载依赖。Linux 需要 Slint 和 rfd 所需的图形、窗口及文件选择器运行环境；构建时还需安装 Qt 开发文件以启用原生文件拖放（Wayland 下运行时需要 Qt Wayland 平台插件）。输入服务器名或 IP、共享名、用户名和密码后点击连接；默认端口为 445，也可以输入 `host:port`。默认文件列表占满内容区，单击文件后在右侧自动预览，也可以下载；选中文件夹或切换目录后收起预览，双击文件夹打开。

连接成功后，服务器、共享名和用户名会保存到本机的应用配置目录。使用“历史连接”可以回填，删除记录后会同步更新文件；最多保留最近 50 条。密码不会保存在历史记录中，选择记录后需要重新输入。历史文件为：macOS 的 `~/Library/Application Support/salt-smb/history.json`，Linux 的 `${XDG_CONFIG_HOME:-~/.config}/salt-smb/history.json`，Windows 的 `%APPDATA%\salt-smb\config\history.json`。具体路径由系统配置目录决定。

## 功能和限制

- 支持目录浏览、批量上传和文件夹递归传输；文件通过分块流式传输，下载使用预读取，上传使用流水线写入。传输在后台线程执行，界面显示进度。
- 使用支持原生拖放的 Slint Qt 后端时，可将本地文件和文件夹拖入文件列表上传。下载通过下载按钮或右键菜单选择保存位置。
- 图片文件在列表中按需加载缩略图（PNG、JPEG、GIF、WebP、BMP；文件不超过 16 MiB，最多 4 张同时读取和解码）。缩略图只保存在当前列表中。
- 支持 UTF-8 文本预览（最多 256 KiB）和常见图片预览（远程文件最多 8 MiB）。拖动文件列表与预览之间的分隔条可调整两侧宽度；本次运行中保留调整后的比例。其他格式请下载后用本地应用打开。
- 上传使用独占创建，同名文件和目录不会被覆盖。上传中断可能在共享目录留下不完整的文件或目录，需要手动清理。下载也不会覆盖本地文件或目录，失败时尝试清理当前不完整文件；已经传输的文件和目录会保留。传输不跟随符号链接。
- 列表和图标视图中可勾选多个文件或文件夹，再点击“下载已勾选”并选择目标目录；遇到错误时停止，已完成的项目保留。
- 当前一次执行一个操作，不支持任务取消和断点续传。密码只保留在进程内，不保存到磁盘。
- 尚未对特定 Samba 服务器或网络条件进行性能基准测试；实际速度取决于网络、服务器和文件系统。

SMB 协议由 [smb2](https://docs.rs/smb2/0.37.0/smb2/) 提供。部署前请根据服务器安全策略检查 SMB 签名和加密配置，以及所选 Slint 版本的许可条件。

文件区支持列表和图标视图切换。列表显示文件类型、大小和修改时间；可按名称、类型、大小或修改时间升序或降序排序，文件夹始终排在文件之前。

在文件项目上按住 Ctrl（macOS 也可按 Command）并滚动鼠标滚轮，可分别调整列表和图标视图的大小。右键项目可打开文件夹、预览或下载文件、重命名、删除及刷新目录；删除文件夹仅支持空文件夹。
