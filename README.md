# Salt SMB

使用 Rust、Slint 和纯 Rust SMB2/3 客户端构建的桌面文件客户端。

## 运行

安装 Rust 工具链和系统图形环境，在项目目录运行：

```sh
cargo run --release
```

首次构建需要访问 crates.io 下载依赖。Linux 还需要 Slint 和 rfd 所需的图形、窗口及文件选择器运行环境。输入服务器名或 IP、共享名、用户名和密码后点击连接；默认端口为 445，也可以输入 `host:port`。双击文件夹打开，选中文件后可以预览或下载。

## 功能和限制

- 支持目录浏览、单文件上传和下载；文件通过分块流式传输，下载使用预读取，上传使用流水线写入。传输在后台线程执行，界面显示进度。
- 支持 UTF-8 文本预览（最多 256 KiB）和常见图片预览（远程文件最多 8 MiB）。其他格式请下载后用本地应用打开。
- 上传使用独占创建，同名文件不会被覆盖。上传中断可能在共享目录留下不完整的文件，需要手动清理。下载也不会覆盖本地文件，失败时尝试清理不完整文件。
- 当前一次执行一个操作，不支持任务取消、断点续传、批量传输或目录上传。密码只保留在进程内，不保存到磁盘。
- 尚未对特定 Samba 服务器或网络条件进行性能基准测试；实际速度取决于网络、服务器和文件系统。

SMB 协议由 [smb2](https://docs.rs/smb2/0.37.0/smb2/) 提供。部署前请根据服务器安全策略检查 SMB 签名和加密配置，以及所选 Slint 版本的许可条件。
